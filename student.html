Project details

Project title

Durvish Web Studio: a business website for local shops, built with only HTML and CSS.

Objective

To build a real-world, mobile-friendly website that helps small businesses show their services and get customers online.

Technologies used

  • HTML5
  • CSS3

Concepts practised

  • Semantic HTML tags
  • Flexbox and CSS Grid
  • Responsive design with media queries
  • CSS variables, animations and transitions
  • CSS-only tabs, accordion and dark mode

Problem statement

Many local businesses have no website. Customers cannot see prices, timings or contact details online, and the owners lose business to competitors who appear on Google.

Future scope

Add JavaScript for a cart and search, a backend with a database for online orders and booking, UPI payments, SEO, and reuse the template for clinics, salons, gyms and coaching centres.
